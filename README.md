 Coffee Shop Sales Analysis — Exploratory Data Analysis (EDA)

This project performs an in-depth Exploratory Data Analysis (EDA) on a coffee shop’s transactional dataset to uncover meaningful business insights, identify top-performing products, evaluate store performance, and understand customer purchasing patterns.

 Project Overview

The dataset contains detailed information about transactions, including product category, product type, unit price, quantity sold, store location, and timestamps.
The analysis focuses on cleaning the data, preparing it for exploration, and answering key business questions using visualizations and summary statistics.

 Key Insights

Total Items Sold: 2,14,470 units
